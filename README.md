# Portfólio - Nivea Cris

Este é o meu portfólio profissional, desenvolvido como uma landing page moderna, responsiva e segura.  
O projeto foi construído com **HTML + TailwindCSS**, possui **dark mode automático** e está otimizado para **SEO**.

---

## 🚀 Tecnologias utilizadas
- **HTML5** para estrutura
- **TailwindCSS** para estilização moderna e responsiva
- **Vercel** para deploy gratuito e seguro
- **GitHub** para versionamento e hospedagem do código
